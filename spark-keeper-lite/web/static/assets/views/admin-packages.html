套餐配置建议

· 账号上限决定用户能绑定几个抖音账号，超出会返回 account_limit 错误。

· 每日次数是「每个账号每天自动执行的次数上限」，手动执行同样计入。

· 体验卡建议把价格设为 0，用户点购买时会直接生成 0 元订单并用卡密流程开通。

· 删除已被订单引用的套餐时，系统会自动改为「下架」而不是物理删除，避免订单失去关联。
